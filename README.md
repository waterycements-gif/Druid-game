

# Druid game
Druid game is a survival wave game where you use spirits to attack enemies, each spirit except the starting one is claimed by defeating a boss after every 5 waves.
You gain moves after getting enough experience to level up, each time you level up you will be given choices of what moves you can unlock based on your spirits that you currently have unlocked, as well as an option to heal yourself by 50% of your max health. 

### This project is meant to be played on a PC

Controls:

LMB - Basic attack

A, D - walk left and right respectively

Q - Dash, whatever direction you are walking in determines the direction

SPACE - Jump

J, K, L, I - You press these keys in a sequence to use a move, the starting letter indicates which slot that spirit is in respectively, you can see your current moves and their keys in the pause menu

P.S.
the 'Deer' and 'Bear' spirits are both obtained on wave 5, its just a 50/50 whether one or the other appears, while only the mantis boss is found on wave 10
After wave 10, you can go into endless mode where the enemies get a bit stronger each time you kill the mantis boss at the end
