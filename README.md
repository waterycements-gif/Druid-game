

# Druid game
Druid game is a survival wave game where you use spirits to attack enemies, each spirit except the starting one is claimed by defeating a boss.
You gain moves after getting enough experience to level up, each time you level up you will be given choices of what moves you can unlock based on your spirits that you currently have unlocked, as well as an option to heal yourself by 50% of your max health.

P.S.
the 'Deer' and 'Bear' spirits are both obtained on wave 5, its just a 50/50 whether one or the other appears
